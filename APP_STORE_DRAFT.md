## Description

Neuron Snake is a fast, hypnotic arcade game that reimagines classic snake as a glowing neuron threading its way through a neural grid.

Collect signals, extend your branching path, and survive longer as the board tightens around you. The game is built for quick restarts and satisfying near-misses, with a neon visual style that makes every run feel electric.

Features:

- Classic snake-style gameplay with a neural sci-fi look
- Fast sessions built for repeat runs
- Leaderboard support
- Optional one-time purchase to remove ads
- Mobile-friendly controls and polished native app shell
